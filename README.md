# Intelligent Agents (CSCI 8551)

### Advanced Graduate Research Seminar | University of Minnesota
* **Language/Stack:** Python, C#, .NET
* **Core Focus:** Autonomous Decision-Making, Reinforcement Learning, and Multi-Agent Simulation

---

### Course Overview & Scope
This repository houses advanced architectural implementations modeling agent logic, multi-agent interactions, and environment observation spaces. The codebase bridges object-oriented simulation layout with decoupled decision-making modules.

### Key Work Completed
* **Skyteam Agent Framework (`/Skyteam`):** Engineered a modular, multi-file C# agent environment mimicking strategic scenario planning (`scenario.cs`), game state serialization (`state.cs`), action tracking (`actions.cs`), and sensory observations (`observation.cs`).
* **Autopilot Module (`/Autopilot`):** Programmed a decoupled Python simulation tracking flight mechanics, evaluating real-time logger inputs (`gamelogger.py`), and adjusting control surfaces through algorithmic heuristics (`strategies.py`).

### Skills & Technologies Applied
* **Architectural Engineering:** Decoupled Simulator-Agent patterns, Object-Oriented System Modeling, Finite State Automata.
* **Intelligent Control:** Multi-Agent Heuristics, Policy Strategy Patterns, Observation Parsing pipelines.
* **Tooling:** C# / .NET Project Core (`.csproj`), Python 3, Multi-language systems.
